# Alsarmini Distributor

## العربية

### فكرة المشروع

**Alsarmini Distributor** هو تطبيق ويب بسيط يساعد على:

- إدخال أسماء الطلاب يدويًا.
- قراءة بيانات الطلاب من ملف Excel.
- ترتيب الأسماء أبجديًا.
- توزيع الطلاب بالتساوي على عدد من الفئات.
- عرض نتيجة التوزيع بطريقة واضحة ومنظمة.

### التصميم

تم تصميم المشروع بواجهة بسيطة وسهلة الاستخدام، وتحتوي على:

- مساحة لإدخال أسماء الطلاب.
- خيار لتحديد عدد الفئات.
- زر لتنفيذ التوزيع.
- بطاقات منفصلة لعرض كل فئة وعدد طلابها.
- ألوان هادئة وتصميم متجاوب يعمل على الحاسوب والهاتف.
- دعم اللغة العربية واتجاه الكتابة من اليمين إلى اليسار.

### طريقة العمل

1. يكتب المستخدم أسماء الطلاب أو يرفع ملف Excel.
2. يتعرف التطبيق على بيانات الطلاب ويرتبها.
3. يحدد المستخدم عدد الفئات.
4. يوزع التطبيق الطلاب بالتتابع وبشكل متقارب في العدد.
5. تظهر الفئات والطلاب أمام المستخدم.

## English

### Project Idea

**Alsarmini Distributor** is a simple web application that helps users to:

- Enter student names manually.
- Read student data from an Excel file.
- Sort names alphabetically.
- Distribute students equally among groups.
- Display the result in a clear and organized way.

### Design

The project has a simple and easy-to-use interface with:

- A text area for entering student names.
- An option to select the number of groups.
- A button to start the distribution.
- Separate cards for displaying each group and its student count.
- Calm colors and a responsive layout for computers and phones.
- Arabic language support with right-to-left text direction.

### How It Works

1. The user enters student names or uploads an Excel file.
2. The application reads and sorts the student data.
3. The user selects the number of groups.
4. The application distributes the students in order and keeps the groups as balanced as possible.
5. The groups and students are displayed on the screen.
